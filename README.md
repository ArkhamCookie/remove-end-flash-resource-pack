# Remove End Flash

A simple Minecraft resource pack that removes [end flashes](https://minecraft.wiki/w/End_sky#End_flash).

## Packaging

```shell
zip -r remove-end-flash.zip assets/ LICENSE pack.mcmeta pack.png
```
